## 2025-01-19 - JSON Standardization vs Size Optimization
**Learning:** Attempting to optimize JSON file size by stripping whitespace from embedded Base64 strings was overshadowed by the size increase caused by enforcing standard `indent=4` formatting on previously inconsistently formatted files. While `consoles` and `online` (minified) saw size reductions (~1KB total), the pretty-printed files grew in size. Additionally, the original files contained invalid trailing commas, preventing standard parsing until fixed.
**Action:** When optimizing text-based data files, separate the goals of "validity/formatting" and "size optimization". For size, minification is king. For readability (valid JSON), accept the size penalty or use a more compact pretty-print style if possible. Always validate JSON syntax before attempting structural optimizations.
